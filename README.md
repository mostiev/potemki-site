# Потемки — маленький свечной заводик

Сайт-магазин свечей ручной работы. Опубликован на https://potemki.shop через GitHub Pages.

- `index.html` — готовый сайт (собранный файл, его отдает GitHub Pages).
- `src/template.html` — исходник: верстка, стили, каталог товаров, статьи.
- `src/img/`, `src/logos/` — фото и логотипы, вшиваются при сборке.

Сборка после правок: `python3 src/build.py`, затем коммит и пуш в `main`.
